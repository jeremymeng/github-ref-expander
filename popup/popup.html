GitHub Ref Expander

Rewrites bare references like #1234, owner/repo#1234, or GH-1234 typed into GitHub comment/description boxes into a fully-qualified permalink ([#1234](https://github.com/owner/repo/issues/1234)), so the link keeps working even if the issue is transferred to another repo or the text is copied elsewhere.

When this is off, hover over a detected reference in a textarea to see a small ⚲ button you can click to expand it manually. Press Ctrl+Shift+L (Cmd+Shift+L on macOS) any time to expand every reference in the focused textarea (or just the current selection).
